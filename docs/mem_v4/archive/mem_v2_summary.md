# MemV2 Summary — Historical Reference

MemV2 established the durable shape that remains in the product: compiled
Markdown wiki memory is more useful than replaying raw transcripts; raw lesson
evidence, review candidates, and curated pages are separate layers; and every
durable change is teacher-approved.

It also established one canonical home per fact. Course progress belongs in
canonical lesson/course rollups rather than duplicated compact state pages.
Detailed experiments, retired UI maps, and completed PR checklists were removed
during doc consolidation and remain in Git history.
