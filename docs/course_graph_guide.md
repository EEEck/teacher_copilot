# Review your course map in five minutes

Start from the class **Course** action, then **Network**. On a wide screen, select
a node in the canvas; on a small screen, search the outline. Both open the same
inspector. The map connects concepts to curriculum evidence and approved material.
It is a partial working map, not a prescribed timetable or a record of mastery.

## Try it with conductivity

1. Select **Elektrische Leitfähigkeit von Salzen und Salzlösungen**. Read the
   learning goal first. Could you assess it with one short pupil explanation?
2. Read its connections using the meanings below. For conductivity, ask whether
   the pupil needs to know that ions are charged and can move, or also needs the
   advanced explanation of how ions form and the energetics of hydration.
3. Open the material reference ending **p. 1**. Check the actual explanation:
   solid NaCl already contains ions; they are fixed in the lattice. In solution,
   mobile ions carry charge. Dissolving does not produce free electrons.
4. Open **p. 2** and compare the partner tasks with the learning goal. The question
   about sugar checks whether pupils distinguish dissolving from making mobile
   charged particles available. An activity being linked is not proof of learning.
5. In ordinary **Create lesson plan**, ask: “Plane 45 Minuten zur Leitfähigkeit
   von festem Salz, Salzlösung und Zuckerlösung. Nutze das freigegebene Kursmaterial.
   Prüfe zuerst Ladung versus Beweglichkeit; Partnerarbeit, kein Experiment.”
   Check the cited material and the proposed sequence before saving. After teaching,
   use **Update Memory** to record what pupils actually understood and what remains.

## Read the connections

| Inspector label | Read it as | Your review question |
| --- | --- | --- |
| Builds on X | This concept requires X at the stated level. | Could pupils understand this goal without X? If yes, this arrow may be too strong. |
| Used by X | X builds on the concept currently selected. | Is that a sensible next application? This is the reverse view of the same dependency. |
| Related to X | These ideas help explain or compare one another. | Is the connection useful even though neither must necessarily come first? |

A source citation supports content; it does not automatically justify a prerequisite
or prescribe your lesson order. “Adopted” means approved into the map, not taught.
Canvas positions do not represent dates and are not saved in this MVP.

## Review new material before it enters the map

Under **Materials**, upload a chapter PDF. Check extracted text, formulas, page
bounds and section titles. Save corrections, run the document review, and approve
the chapter. Then **Connect to course map** proposes concepts and section mappings.
Review the proposal, save any edits, rerun review, then approve the changes.

For each proposal check: does this reuse an existing idea, does the section really
explain/practise/assess/extend that idea, and does any new prerequisite pass the
question above? A section may explain only part of a broad concept; record that
limit in its teacher note. Model acceptance is an aid to your review, not a
substitute for checking the chemistry and suitability for your class.

The adopted canvas and inspector are read-only. You cannot currently draw an arrow
or edit any existing concept directly there. Proposal forms expose selected edits;
general corrections to the adopted graph require the supported backend proposal
workflow. Record a correction as “A → B: change Builds on to Related to, because…”
so it can be applied and reviewed precisely. Do not try to correct the graph by
asking the ordinary lesson-planning chat to write it.
