# Chemistry competency model

The Bavarian Fachprofil describes four competency domains. Select the domains that the lesson actually exercises.

- Sachkompetenz: explain substances, particles, structures, properties and transformations.
- Erkenntnisgewinnungskompetenz: ask questions, hypothesize, plan/perform experiments, interpret data and use models.
- Kommunikationskompetenz: document, represent, discuss and present chemical reasoning with correct terminology.
- Bewertungskompetenz: evaluate evidence, applications, risks, sustainability and decisions.

For each lesson, connect the selected domain to an observable student product rather than listing all four as decoration.
