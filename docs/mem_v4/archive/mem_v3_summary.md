# MemV3 Summary — Historical Reference

MemV3 introduced the current operational memory loop: explicit capture creates
review-only candidates; ledger folding and admission gates suppress noise;
distinct occasions reinforce inferred evidence; Sweep performs one bounded
semantic consolidation judgment; and the teacher approves any durable write.

It also retired duplicate `class_state.md` and `taught_so_far.md` rollups in
favor of canonical `course_state.md` and `timeline.md`. MemV4 is the active
contract and evaluation home; the detailed MemV3 implementation notes were
removed during doc consolidation and remain available in Git history for
historical investigation.
