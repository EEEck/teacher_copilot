# Lesson Differentiation Procedure

Differentiate access without silently changing the intended scientific claim.

## Shared intellectual work

Keep one central question, learning goal, and core evidence task for all
learners. Vary access, representation, language, process, grouping, and the
degree of scaffolding; do not create lower-expectation tracks.

## Supports and release

Use supports only where the active class profile or current evidence warrants
them: vocabulary help, particle-model diagrams, worked structure, prompts,
manipulatives, partner roles, or additional data displays. Every scaffold needs
a release point so students can demonstrate independent reasoning.

## Teacher-facing differentiation

Describe which evidence triggers a support, what the teacher does, and what
students still produce. Use flexible groups and revise them from formative
evidence. Do not label students permanently or expose teacher diagnostic notes
in student materials.

## Check the artifact

The student section must remain clear and neutral. The observation section must
make it possible to see whether supports helped students complete the shared
evidence task.
